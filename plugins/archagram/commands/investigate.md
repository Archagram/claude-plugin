---
description: Record an investigation in Archagram from captures, logs, traces or code
argument-hint: "[what to investigate]"
---

Record what a running system was observed to do as an Archagram investigation, by following the record-investigation skill from this plugin.

Use the subject and the evidence the user gave with this command, if any. Ask for the project, for the evidence to read (a network capture, logs, traces or code) and for the environment and the time it comes from before writing anything.

Finish with what the investigation covers, what stands out, and the questions left open as notes.
